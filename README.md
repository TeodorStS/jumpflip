JumpFlip

A Flappy Bird-style browser game made for the students of TU Dublin by the CS++ Society. Students played it at society events for a chance to win a reward, and signed up to the society along the way.

Hosting

JumpFlip was hosted on the CS++ Society's own server at TU Dublin, so students could open it straight from their phones on campus.

How it worked
Students scanned a QR code at the CS++ stand.
They entered their name and student number and played.
Their best score went onto a live leaderboard shown at the stand.
The top scorers were rewarded by the society.
Stand display (/display)

A read-only screen for a laptop or TV at the stand. It shows:

a QR code to the game and a QR code to the society sign-up
the live leaderboard, refreshing itself every few seconds
running totals for players and games played

Move the mouse over it to choose how many players to show (top 10, 20, or any number up to 100). If the server becomes unreachable, the board keeps the last scores on screen instead of going blank. The QR codes are generated by the server itself, so the screen works without an internet connection to third-party services.

Organiser page (/dev)

A password-protected page for the society committee. Any username works; the password is the ADMIN_PASSWORD set on the server, and the page stays switched off if none is set. It lets organisers:

see every player with their student number, best score, number of attempts and last played time
search by name or student number
export the full list as a CSV to pick the winners
delete a player, or a single attempt (the player's best score is recalculated)
watch a live monitor with players, attempts, top score and games in the last 10 minutes

Because it shows student numbers, it is never put on the stand screen.

Tech

Node.js, Express, SQLite, and plain JavaScript on an HTML canvas. It runs as a single Docker container.

Run it locally
npm install
npm start

Open http://localhost:3000. Or with Docker:

docker compose up -d --build

Optional environment variables: PORT (default 3000), DB_DIR (where the database is stored), and ADMIN_PASSWORD (turns on the organiser page).

Project layout
server.js    Express app and API routes
db.js        SQLite schema and queries
public/      The game, stand display and organiser page
scripts/     CLI tools for inspecting and backing up the database
Data

The app stores each player's name, student number and scores, used only for the event leaderboard.
